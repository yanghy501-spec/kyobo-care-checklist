# 맞춤관리 체크리스트 (모바일)

교보생명 유성미래지점 맞춤관리 체크리스트를 QR로 열어 휴대폰에서 작성하는 페이지입니다.

- 게시 주소: https://yanghy501-spec.github.io/kyobo-care-checklist/
- 유입 경로 구분: 주소 끝에 `?src=video`, `?src=print` 등을 붙이면 시트에 함께 기록됩니다.
- 응답 저장: `index.html` 안의 `CONFIG.ENDPOINT`에 구글시트 Apps Script 웹 앱 주소를 넣어야 저장됩니다. 비어 있으면 미리보기 모드이며 제출 내용이 저장되지 않습니다.
- QR 배포 후에는 저장소 이름을 바꾸지 마세요. 주소가 바뀌어 기존 QR이 연결되지 않습니다.
